This site uses Jekyll so it can be published through GitHub Pages with a lightweight, static architecture. The structure separates layout, style, and content to make future writing easy.

The design uses a professional, high-contrast palette with responsive cards, semantic landmarks, a skip link, and ARIA labels to support accessibility.

The tool stack includes:

- Jekyll for static site generation
- GitHub Actions for automated build and deployment on pushes to `main`
- Markdown pages for straightforward content authoring
